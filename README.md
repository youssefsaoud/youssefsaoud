## 01 / About

I enjoy the side of software development that users rarely see.

The APIs connecting services, the database decisions that shape how information flows, the security boundaries that protect an application, and the architectural choices that make code easier to maintain.

My primary focus is **Java and the Spring ecosystem**, with hands-on work across REST APIs, authentication and authorization, relational databases, and full-stack applications.

I learn by building, questioning design decisions, and improving what I've already written.
