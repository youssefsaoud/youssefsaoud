### 🚀 About Me

> *"Good software isn't just about making things work. It's about understanding why they work."*

- ☕ **Backend Development:** Building applications with **Java, Spring Boot, Spring Data JPA, and Hibernate**.
- 🔐 **Security & APIs:** Working with RESTful APIs, JWT authentication, Spring Security, and role-based authorization.
- 🗄️ **Database Engineering:** Designing relational database schemas and working with **PostgreSQL and SQL**.
- 🏗️ **Software Design:** Interested in object-oriented design, maintainable code, and backend architecture.
- ⚙️ **Developer Tools:** Building practical automation tools and exploring ways to improve development workflows.
- 🌱 **Continuous Learning:** Improving my understanding of software engineering through real projects, experimentation, and technical writing.
